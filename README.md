# 가동ON 사이트 (1단계 · 뼈대)

## 처음 실행 (담당자님 PC, Windows)
1. **Python 설치** (한 번만): https://www.python.org/downloads/ 에서 3.11 이상 설치.
   설치 첫 화면의 **"Add python.exe to PATH"** 체크.
2. 이 폴더의 **`시작.bat`** 을 더블클릭.
   - 처음에는 필요한 프로그램(Flask, pandas, openpyxl)을 자동 설치합니다 (1~2분).
   - 이어서 **관리자 아이디와 비밀번호**를 물어봅니다 (비밀번호 8자 이상, 입력할 때 화면에 안 보이는 게 정상).
3. 브라우저가 열리면 **http://127.0.0.1:8800** 에서 로그인.
4. 다음부터는 `시작.bat` 만 더블클릭하면 됩니다. 끌 때는 검은 창을 닫으세요.

## 화면 (역할별)
| 역할 | 볼 수 있는 화면 |
|---|---|
| 관리자 | 관리자 대시보드(이름 포함 전체), 투입계획 업로드(전체 내역·상태 처리·원본 다운로드), 주차·게시, 사용자, 접속·변경 기록, 회의용 |
| 업로드 담당자 | 투입계획 업로드(**담당 부서로 고정**), 내 업로드 내역, 회의용 |
| 회의 참석자 | 회의용 대시보드만 (관리자가 게시한 최신 주차) |

- 회의용 대시보드: 발표 모드 6장 (요약 · 본부별 · 추이 · 대기 인력 · 인사 변동 · 특이사항).
  키보드 ← → 로 넘기기, '전체 화면', 'PDF·인쇄' 버튼.
- 계정은 관리자 화면 **사용자** 메뉴에서 만듭니다. 업로드 담당자는 담당 부서를 꼭 지정하세요.

## 주차 규칙
그 주(월~일)의 **목요일이 속한 달 기준** 순번. 예) 10/1(목)이 있는 주 = 10월 1주차, 10/6이 있는 주 = 10월 2주차.
그 주 목~금에 통계를 보내고 **다음 주 월요일 회의**에서 봅니다. (예: 10월 2주차 자료 → 10/12(월) 회의)

## 매주 하는 일 (재계산)
1. 담당자가 **투입계획 업로드** (부서 고정). 관리자는 SOLD·가동인력목록·통합인사정보·가동가득 통계·CP도 올릴 수 있음
   - 올리는 순간 양식을 검사해서 "어느 자리에 반영되는지" 보여 줌. 양식을 모르면 거부
2. 관리자 → **주차·재계산·게시** → `재계산` (5~10분, 화면이 자동 새로고침)
3. **새 계산본** 미리보기(회의용·관리자) + **점검 목록**(대기 명단 대조, 1.00 초과 보정, SOLD 우선 적용 등) + **이번 계산에 쓴 파일** 확인
4. `계산본 게시` → 회의용 화면에 반영, 쓰인 업로드는 '반영'으로 바뀜

## 어떤 파일이 쓰이나 (자리별 최신 1개)
| 자리 | 쓰이는 파일 |
|---|---|
| 1~9월 실적 | SOLD투입MM목록 (클로잇 / 엔텍) |
| 가동대상 | 가동인력목록 (클로잇 / 엔텍) + 통합인사정보조회 (AX) |
| 10~12월 | 부서 투입계획 > 하반기 총괄(최신) · EC1·2 / 클로잇 ES / AX / 엔텍 ES / 엔텍 EM 는 고정 자리, 그 밖의 부서가 올린 파일은 그 부서에만 적용 |
| 최종 기준 | 가동가득 통계 — 올라와 있으면 조직 숫자·대기 명단을 통계에 맞춤 |
- 해당 주차까지 올라온 업로드 중 최신(보류·반려 제외), 없으면 `storage/inputs/base` 의 기본 파일(10월 2주차 기준)을 씀
- 규칙(엔텍 SOLD 우선, 1.00 초과 보정, 이대근 휴직, MSP 전배자 SOLD 기준, 백재현 제외, 김영관 대기 명단 오기 등)은 그대로 적용

## 한계 (다음 단계)
- 계산 로직의 '당월'은 **10월** 기준으로 고정. 11월 첫 주 전에 월 전환 작업 필요
- 전주 대비 비교는 주차가 쌓이면 연결 예정

## 비밀번호를 잊었을 때
`비밀번호재설정.bat` 더블클릭 → 아이디 입력 → 새 비밀번호 두 번. 잠금도 같이 풀립니다.

## 보안
- 비밀번호는 암호화(해시)해서 저장, 5번 틀리면 10분 잠금, 8시간 지나면 다시 로그인.
- 업로드는 .xlsx/.xls, 20MB 이하만. **매크로 포함 파일은 거부**. 저장 시 파일 이름을 무작위로 바꿔 보관.
- 모든 입력 양식에 위조 요청 방지(CSRF) 적용, 화면 출력은 자동 이스케이프.
- 기본은 **이 PC에서만 접속**됩니다. 사내망 다른 PC에서 열려면 `py app.py --lan` 으로 실행
  (사내 보안 정책 확인 후 사용, 외부 인터넷에 공개하지 마세요).
- `storage` 폴더에는 **인사정보·업로드 원본·계정 DB**가 쌓입니다. 이 폴더는 메일·메신저로 보내거나 공유 폴더에 올리지 마세요.
